# Selenium WebDriver Assignments

This repository contains my Selenium WebDriver assignments completed using Python. 
The assignments demonstrate different Selenium concepts such as web element identification, 
handling multiple elements, CSS selectors, and navigating child nodes.

## Technologies Used

- Python
- Selenium WebDriver
- Google Chrome
- ChromeDriver / Selenium Manager
- HTML
- Git & GitHub
